Parking Management System

Introduction

This system automates parking operations including vehicle entry, slot allocation, session tracking, and payment management.

Features

  • User & Vehicle Management
  • Slot Allocation System
  • Parking Session Tracking
  • Payment Processing
  • Data Analysis using Pandas & Plotly

Technologies Used

Python, MySQL, Pandas, Plotly, HTML, CSS

Conclusion

The system provides an efficient and automated solution for modern parking management.
